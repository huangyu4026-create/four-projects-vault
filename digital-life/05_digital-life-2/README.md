这是 P01 数字生命从“资料库＋查询系统”迈向“可回源、可修订、可反证、可校准、可受控调用的个人模型”的第一个正式版本。

## 目录

- `design/`：总纲、对象契约、对接规则、验收标准和实施回执。
- `tools/`：SQLite迁移、双阶段写入、版本链、校准、上下文包、回执和N01—N15验收。
- `ui/`：本地操作台的四视图前端。
- `contracts/`：P05与LWG的最小上下文包接收契约。
- `database/`：数据库哈希和 GitHub Release 附件说明。

## 数据库

正式 SQLite 主库约267MB，超过普通 Git 的100MB单文件限制，因此作为 GitHub Release 附件发布，不塞入 Git 历史。仓库不包含令牌、密码、`.env`、WAL/SHM、缓存和历史重复备份。
